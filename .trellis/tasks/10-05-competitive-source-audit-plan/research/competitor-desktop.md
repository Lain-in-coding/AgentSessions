# Research: 桌面与浏览型竞品源码审计

- Query: 对本地 agentsview 与 agent-sessions 的桌面/浏览、检索索引、provider、上下文、恢复、隐私、安装测试做只读证据审计。
- Scope: mixed（本地源码为准；外部文档仅做约束参考）
- Date: 2026-10-05

## Findings

主线程补充了下面的源码取证结论。最初的研究员限流，原有全量路径清点予以保留；清点不代表逐行阅读完成。没有运行桌面应用或其测试，视觉体验与 macOS/跨平台安装未实测。

### agentsview — a84564a：Go 后端 + Svelte 前端，不是 TS CLI

- `internal/db/search.go:342-419`：FTS + session name/first-message 分支，排除 system/deleted 数据，按 relevance/recency 和 session_id 排序；以 session 命中和 message ordinal 为单位服务 UI。
- `internal/mcp/tools.go` 的 searchSessions 和 getMessagesAround / sessionOverview 暴露任务级接口；MCP source graph 与测试入口存在，本轮未运行测试。
- `internal/vector/search.go:91-139`：query 编码、active fingerprint generation、无索引 vs 正在构建的显式错误及进度，不是简单“有个向量搜索”标志。
- `internal/vector/search.go:171-187`：批量 hydrate hits，mirror 中被并发移除的文档有明确处理语义。
- `frontend/src/lib/components/sidebar/SessionItem.svelte:30-62,82-109`：continuation chain / subagent / teammate、活动状态与分组的 UI 模型；`215-242` 的重命名/删除错误被 catch 且无用户反馈，不是完美 UX，ASG 不应照抄。
- 前后端、向量镜像、桌面、MCP、远端/团队功能增加维护面。本地目录含大量测试和前端资源，不能把总行数等同产品复杂度或质量。

**ASG 应学**：让会话结构、命中位置、工作状态和下一步在一次浏览里可见；给索引 readiness 具体状态。**不该学**：为了“入口齐全”立刻增加团队云服务；不要复制吞掉 UI 操作错误的行为。ASG 与它比的不应是宣传里的 provider 数，而是相同问题是否更快定位到正确原文。

### agent-sessions — af4793d：macOS Swift/SwiftUI 原生应用，不是 Go CLI

- README:1-24：macOS 14+，已提供 4.6.3 DMG 链接（本轮未下载验证）；主产品同时强调 quota/usage 和可检索会话，并非与 ASG 完全相同的定位。
- `AgentSessions/Model/SessionSource.swift:4-27`：10 个 source enum；数量和 ASG 的 variant/provider/maturity 口径不能混用。
- `AgentSessions/Services/SessionIndexer.swift:1326-1334`：从 session_meta 冷启动恢复，避免首次 UI 再全扫。
- `SessionIndexer.swift:1391-1405,1851-1855`：有界 backfill 和 session_index.jsonl thread-name 覆盖；这些“用户看到标题是否及时更新”的细节比堆后端术语更直接。
- `AgentSessions/Search/SearchCoordinator.swift:633-648`：stale/unindexed 会话有明确补扫策略，避免长 hot transcript 因索引延迟而搜不到。
- `SearchCoordinator.swift:655-699`：Instant search 将多词视为 phrase、简单 ASCII 长词自动 prefix；它与 ASG literal/CJK bigram 语义不同，不能按一个 query 的结果数粗暴比较。
- `AgentSessions/Services/OpenClawSessionIndexer.swift:491-543`：解析前后 stat、文件变化后的重试路径与只读 transcript cache；没有证据就不能声称它没有 freshness 处理。

**ASG 应学**：搜索与详情跳转、缓存启动、sidecar 标题/状态更新、对未索引内容的新鲜度提示。**不该学**：在 CLI-first 首发前重写一个 macOS-only GUI 或 quota 仪表盘。ASG 的跨平台命令接口和可验证证据契约仍有自己的价值。
